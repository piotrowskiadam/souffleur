# Souffleur audit — 2026-10-31

Scope: all tracked source, both MV3 manifests, build tooling, release workflow and project documentation at baseline `8ebe193e933005622771e2762ea68398fb59a3a2`. The user authorized implementation and GitHub updates, selected refinement of the current dark UI, and chose local storage with JSON import/export over ongoing browser-account synchronization.

## Implementation integrity verdict

The baseline had a coherent, small, framework-free product and useful Shadow DOM isolation, but its storage and DOM-rendering boundaries were unsafe to extend. The implementation now centralizes mutation/validation, separates browser-independent data logic, and keeps both browser variants on one source tree. Prompt data is rendered literally, the UI reports failures, and tests enforce important cross-context behavior.

Impeccable’s mechanical detector returned **zero findings** (`[]`) across the changed content script, both UI stylesheets, shared theme, panel HTML and panel script. This is a static design-pattern check, not a security or WCAG certification. The visual assessment used actual browser screenshots, not detector scores alone.

## Positive baseline choices retained

- One shared source tree instead of browser-specific application forks.
- No runtime framework, backend, account or model-service dependency.
- Stable prompt IDs, a simple JSON export format and a useful clipboard-first interaction.
- Shadow DOM for style isolation and a native browser sidebar/panel.
- Existing dark palette, purple/cyan identity, extension icons and store IDs.

## Residual constraints and next work

1. Before store publication, run a native Firefox sidebar/shortcut/clipboard smoke check and manual screen-reader/forced-colors checks on the actual supported browsers. Automated Firefox UI execution and `web-ext lint` do not test Mozilla signing or every native sidebar lifecycle.
2. The retained legacy sync key may still exist in browser-vendor cloud storage. The new version does not update it; documented removal is an explicit post-backup operation. Cross-device live sync was deliberately removed with the user’s approval.
3. Shadow DOM and event bubbling protection cannot hide an open prompt preview from an untrusted host page or prevent that page’s capture-phase listeners. Closed Spotlight clears previews, queries and cached arrays.
4. Local backup is one previous replacement snapshot, not historical versioning. Keep separate JSON exports. Uninstallation/profile deletion clears local extension storage.
5. Plain search scans the bounded full library. If real-world performance needs exceed 5,000 prompts / 4 MiB, profile representative libraries before adding indexing or virtualization.
6. Track the development-tool advisories and update Mozilla’s validator when compatible fixes ship. The shipped extension has no third-party runtime dependencies.

For a future dedicated UI pass, use Impeccable `harden` for newly observed browser edge cases, `adapt` for any newly supported surfaces, and finish with `polish`. These are follow-up tools, not unimplemented fixes required by this pass.
